03 / GOOD TO KNOW

开始之前，你可能想知道。

还有问题？提交 Issue ↗
任意 harness 都能恢复完整会话吗？+

使用通用文件和接续说明恢复工作。完整程度取决于源端能提供哪些历史、附件和文件；缺失会记录在报告中。目标端需要能下载、读写文件并执行命令。隐藏推理、模型内部状态、活动进程与登录权限不会迁移。

需要先安装 Bun、Node 或 age 吗？+

使用发布的单文件程序时无需额外安装这些环境。Mac 和 Windows 引导使用系统自带工具，程序内部包含 Bun、加密与 Skill 安装能力。其他 Skill 自身依赖的原生工具、第三方包或 MCP 权限仍需目标端具备。

怎样保证装到当前 harness，而不是其他工具？+

安装器使用当前运行信号和上游目录规则，明确的目标或目录优先。无法识别、多个候选或强信号冲突时，会要求显式指定，不向所有检测到的产品安装。使用 detect-harness 可以先预览选择。

交接提示词和临时文件会保留多久？+

交接提示词包含下载信息与解密私钥，请只交给接收方。目前已接入并验证 Filebin，期限以服务端响应为准，通常约七天。删除下载入口无法撤回别人已经下载的副本；项目主页不保存你的任务包或密钥。

本地已经装过，会被覆盖吗？+

可用版本会通过文件校验和本地健康检查，直接复用而不改文件。受管理的损坏安装会先备份再修复。升级健康版本需要明确使用 --replace；健康共享目录链接只读复用，不通过链接替换。
