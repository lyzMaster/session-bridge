01 · FEATURES

Everything the next agent needs
to keep going.

A summary tells the next agent what happened. Session Bridge also brings the evidence, files and capabilities it needs to actually finish the job.

🧠

Real context, not a summary

Requirements, latest corrections, decisions, raw history, attachments and workspace files travel together — with omissions recorded.

🧩

Skills come along

Only Skills with evidence of use are bundled — scripts, assets and instructions — and registered on the target automatically.

🔐

Encrypted before it leaves

age encryption runs locally. Relays only ever store ciphertext; the key lives in your continuation prompt.

⚡

Picks the fastest relay

The first encrypted part is uploaded and read back on Filebin and Temp.sh at the same time; whichever verifies first wins on your network.

🧵

Multipart & resumable

Adaptive 256 KiB–8 MiB parts, up to 6 workers, saved checkpoints and Range downloads — an interrupted transfer picks up where it stopped.

📦

One file, zero setup

A single executable for Windows x64 or macOS 13+ with Bun, age and the Skills installer embedded. No Node, Python or npm.

  • 1prompt to hand off
  • 2relays raced live
  • 0runtimes to install
  • 6×parallel transfer workers
02 · HOW IT WORKS

Three steps.
One continuous task.

  1. 1

    Pack on source

    Send one prompt in your current session. Session Bridge installs or reuses itself, then gathers context, files and used Skills.

    Context + Files + Skills
  2. 2

    Encrypt & relay

    The bundle is encrypted locally, uploaded in verified parts to the fastest relay, and turned into a short continuation prompt.

    Short prompt + full credentials
  3. 3

    Continue on target

    Paste the prompt anywhere. The target downloads, verifies, decrypts and restores into a fresh directory — then keeps working.

    Evidence & workspace kept separate
